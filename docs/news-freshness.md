# NEWSHOT 首页旧闻过滤

实施日期：2026-10-18。此改动目前已在本地实现；线上仍需经 GitHub 部署后生效。

## 展示口径

- 首页按北京时间的滚动 24 小时窗口，使用原文发布时间，不使用采集时间或更新日期代替。
- 先过滤单条来源记录，再进行事件聚类、评分和领域分类。旧报道不会给新事件贡献标题、来源数、热度或排名。
- 首页从全部已配置来源召回：财联社电报、金十普通流、关注微博、RSS、现有平台采集记录。无需热榜排名、重要级别或热度标记；已下榜也不作为排除条件。原文在24小时内且通过时间核验就能进入候选。
- 发布时间缺失、无法核实、明显在未来，或晚于采集时间的记录不进入首页。发布时间不明不等于已证实是旧闻。
- 来源页和历史数据继续保留，不删改上游 SQLite；首页没有合格内容时显示空状态，不拿旧快照补位。
- 平台采集超过 2 小时未更新时提示缓存滞后。构建时间不表示新闻的新鲜度。
- 浏览器打开时、每分钟以及页面恢复可见时复核过期时间。某条来源报道过期后，按服务器预先计算的状态更新事件的标题、来源链接、来源数、分类和排序分；同事件仍有合格报道则保留事件，全部来源过期才隐藏。静态页面不会因缓存或周末暂停采集而永久保留旧内容。

## 发布时间依据

`RawItem.published_dt` 与 `publication_source` 保存原文时间及其依据，`collected_dt` 单独保存采集时间。

- 关注微博：使用源数据 `created_at_ts`，不把导出时间当成发博时间。转发优先使用最初原帖的时间，原帖时间缺失的转发不进入首页；关注微博来源页仍保留转发行为本身及其时间。
- RSS：只使用可解析的 `published_at`；缺失时不回退到抓取时间。
- 金十：标准化记录保留其原生 `time`。
- 文章：在白名单媒体域名的文章页读取明确的发布日期 meta、文章类型 JSON-LD 的 `datePublished`。华尔街见闻读取页面内嵌 JSON 中与 URL 文章 ID 一致的主文章 `display_time`，不使用相关文章的日期。
- 不使用 `dateModified`、页面更新时间、抓取日期、热榜首次出现时间推断发布日。不从只有月日的显示时间猜年份。

媒体公布的原始时间字段仍可能存在上游错误；本机制不声称能核实事件本身发生于该时间，也不能保证识别换标题、换链接的旧闻重发。

## 缓存和请求限制

`tools/news_freshness.py` 为过滤入口，元数据位于 `output/freshness/publication-times.json`，每次运行统计位于 `output/freshness/report.json`。

已确认的原文时间按链接保留，不因再次上榜而刷新。未知结果 6 小时内不反复请求。每次构建最多核验 12 个新链接、并发 2、超时 5 秒、响应大小上限 2 MB；只访问白名单 HTTPS 文章页，并验证跳转目的地。不登录、不绕过验证码或付费墙。超过预算或访问失败的条目暂按时间未知处理，因此首页覆盖量可能减少；之后的构建会继续核验。

`report.json` 中的时效排除原因互斥，包含 `old_publication`、`unknown_publication`、`future_publication`、`future_capture`、`publication_after_capture`；不再因已下榜或不在最后一轮热榜快照中而排除。这里只反映本轮读到的数据，不等于全网内容量。

## 全来源与具体事件聚类

来源开关在 `config/home_sources.json`。`tools/home_source_pool.py` 在构建前更新财联社、金十、界面快报的24小时公开来源池：财联社不按 A/B/C 级别筛选，金十不要求 `important` 或 `hot`，界面读取公开滚动快报列表及其分页，不按热门或重要筛选。每个来源记录窗口是否抓全；请求失败保留缓存，部分抓取保留仍在窗口内的旧缓存条目，不把部分结果宣称为全量。

界面快报使用 `tools/jiemian_flash.py`，仅访问用户指定 `/lists/4.html` 与该页脚本声明的公开 `kuaixun/getlistmore` 接口，分页栏目参数从页面读取，不猜测。使用 `data-time`/`publishtime` 原生完整时间；仅收公开标题、列表摘要和规范化原文链接，不抓文章会员正文。无权限、付费、登录及解锁占位内容跳过，重定向到登录或其他接口会停止；每轮最多24页、30秒、单次8秒、2MB。来源页有固定入口与采集覆盖提示，分类首页复用同一 `jiemian-flash.json` 公开池并参与现有去重聚类。公众号/飞书流程不变。

金十范围为首页公开市场快讯流（普通+重要+热门），并非会员栏目或全站文章。VIP、PLUS、登录/付费受限标志、解锁占位提示和未知权限直接跳过，不登录、不绕过限制。新缓存带 `public_only=true`；未核验的旧缓存不进入来源页或分类候选。来源页和分类首页读取同一公开池；来源页保留不同领域的公开快讯，首页只显示匹配关注领域的事件。每轮最多30秒、每请求最多8秒，空页不等于24小时抓全。`--only jin10-all --force` 可单独刷新金十，不触发其他采集。

本地关注微博名单位于相邻项目 `weiboX-server/local/accounts.json`，目前共11个：21世纪经济报道、新浪财经、蓝鲸新闻、中新经纬、华尔街见闻、贝壳财经、中国经营报、经济观察报、澎湃新闻、证券时报、第一财经日报。名单以用户提供的 UID 为准，新增不会替换旧账号；抓取保持单账号间隔30～60秒、每轮间隔1小时。页面读取采集缓存，不因添加多个来源而并发请求微博。

首页使用 `tools/event_registry.py` 的持久 event—progress—doc 三层模型，匹配特征由 `tools/news_event_clustering.py` 提供，与“热点脉络”的长期话题聚合独立。同一进展汇总来源，不同事实进展分别保留；标题和文章集合变化不重算 ID。采用多个代表报道及受约束的分组修复，避免固定首次锚点漏合并，也避免单链式相似吞并整个话题。详见 [三层模型与验证](event-progress-model.md)。

每个事件只显示一张主卡，详情保留每条来源的原文链接。相同标题来自不同媒体时保留各自链接。同一媒体的网站和微博只计为一个媒体来源，但两个渠道的报道都保留。规则型聚类仍可能漏合并或误合并，可用 `output/source-pool/home-events.json` 逐组复核，不应把来源数量理解为独立事实验证次数。

公众号采集仍按之前的设置停用，未触发公众号刷新，也没有修改飞书链路。首页不会宣称未采到的公众号新内容已覆盖。

## 首页领域

首页筛选固定顺序为：**全部、硬科技、大宗、新消费、汽车、新能源、金融、物流、社会**。规则在 `tools/home_categories.py`，独立于历史脉络和来源页的旧主题标签。

- 按内容而非媒体名称判断，财联社、金十或财经微博也能进入所有领域。一个聚类事件最多归入一个主领域；“全部”仅包含八个领域的事件，未归入领域的内容保留在来源页，不增加额外筛选标签。
- 硬科技包括 AI、芯片、算力、机器人、航天及消费电子；大宗包括贵金属、油气、工业原材料和农产品；新消费包括零售、电商、餐饮、消费品牌，以及视频平台、直播/MCN经营、影视剧综艺、微短剧、游戏、音乐和演出等商品与服务消费。详细边界见[新消费编辑口径](consumer-scope.md)。
- 整车、车企、智驾归汽车；电池、光伏、储能、风电等归新能源。行业公司的融资、财报仍归其行业，不因出现“营收”“上市”一律转为金融。
- 股票/基金交易、银行、货币政策等归金融；黄金、原油等实物商品行情仍归大宗。物流覆盖快递、仓储、货运、港口、航运等，不仅凭“供应链”“出口”等泛词判断。
- 基金、ETF、LOF、QDII、FOF、REITs等产品的停复牌、申赎/认购、限购、分红、折溢价、净值、份额、成交及资金流向优先归金融，不被名称中的芯片、AI、光伏、黄金、汽车等主题词覆盖。金融产品的发行/上市/推出也不等于产业新品发布；“发布分红公告”等表述不能触发产业产品豁免。产业基金投资建厂、企业获基金融资、基金重仓公司的研发及经营财报仍按具体产业分类；只在标题本身缺少领域证据时，才有限利用正文补充交易意图。
- 老鼠仓、内幕交易、利用未公开信息交易、操纵证券市场等证券违规事件优先归金融，不因标题强调判刑或调查而落入社会，也不因涉事公司主营芯片/汽车而变成对应产业新闻。
- 社会只收有明确国内证据的社会民生、公共事件；国际、外交、军事不归社会，国内军演也不以社会兜底。国内地点、机构、事件背景可作为证据，中文标题或中国媒体来源本身不代表国内事件；例如“中国地震台网报道缅甸地震”不归社会。标题未提供地点时，有限检查正文前段；地域不明的综合内容保留在来源页，不强行归社会。
- 国际/军事内容不删除，未进入明确产业领域时只保留在来源页；海外 AI 发布、海外车企财报、国际原油行情等仍归对应产业。不会因为“无人机袭击”就归为硬科技。只有标题缺少领域线索时，才有限使用正文及同事件其他报道补充判断。
- 先判新闻意图，再看科技词：战场行动、领空争议、军方武器研发/量产、外交表态和纯政治会见，不能仅凭无人机、卫星、AI、芯片等词进入产业分类，正文或其他转述也不能绕过此门槛。明确的民用技术、产业政策、企业财务、油价/运价等市场后果、通航及物流设施受损仍按产业归类；战争题材影视/游戏的发行、票房、销量属于文化消费，不按真实军事报道排除。规则不按国家或具体文章设例外。

浏览器中条目过期后，新的事件状态也会按上述领域重新归类，避免重新出现旧标签。规则分类仍可能在跨行业新闻上产生歧义，可在测试中增加有代表性的真实案例进行修正。

## 生成和回归验证

```sh
python3 tools/weibo_feed.py --output-root output --allow-stale
python3 tools/home_source_pool.py --output-root output
python3 tools/curated_events.py --output-root output --lookback-days 2 --current-pages-only
python3 -m unittest discover -s tools -p test_news_freshness.py
python3 -m unittest discover -s tools -p test_curated_home.py
python3 -m unittest discover -s tools -p test_home_sources.py
```

本地定时任务已使用 `--current-pages-only`，同时重建分类首页与来源页，且关闭采集容器的原始 HTML 报告输出，避免覆盖分类首页。没有更改周末停采策略、公众号状态或飞书发送流程。
