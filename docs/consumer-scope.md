# NEWSHOT 新消费编辑口径

2026-10-18按用户要求扩展。本页是本站选题分类口径，不宣称“新消费”有一套唯一、必须照搬的官方行业枚举。

## 定义参考

国务院关于恢复和扩大消费的措施将电子商务、直播经济、在线文娱等列入数字消费；商务部等部门关于数字消费的指导意见涉及影视、动漫、游戏、音乐、网络文学和微短剧。国家发展改革委的数字文化消费文章也涵盖网络视听、在线演艺等。因此，本页从“新品牌”扩展为商品、数字服务与文化娱乐消费，但保留本站已有的其他行业分类。

- [国务院：恢复和扩大消费的措施](https://app.www.gov.cn/govdata/gov/202307/31/505851/article.html)
- [商务部等8部门：大力发展数字消费的指导意见](https://www.mofcom.gov.cn/swbhqzczt/xflt/art/2026/art_bc2ffa1449ab4d79b7088aba22ba3225.html)
- [国家发展改革委：大力发展数字文化消费新业态](https://www.ndrc.gov.cn/wsdwhfz/202209/t20220915_1335531.html)

## 纳入内容

1. 商品与品牌：茶饮、餐饮、美妆、服饰、潮玩、酒类、宠物、家电等，原规则保留。
2. 渠道与平台：零售、电商、即时零售、长短视频、直播、社交内容和数字阅读/音乐/游戏平台的商业化、会员、广告、营收、用户规模、产品服务和治理规则。
3. 直播与创作者经营：MCN、直播机构、主播的复播、商业转型、带货、签约解约、账号注册注销、限流、粉丝增长/流失/清零等。识别三只羊、小杨哥等商业主体，不要求标题必须出现“电商”。
4. 文化内容与服务：电影、电视剧、剧集、综艺、动漫、短剧、游戏、网络文学、音乐和演出。包括作品供给、上映/定档/开播、票房、会员收费、付费、版号、版权、分账、发行、票务和用户权益。

“疯狂小杨哥新号粉丝被清零”按直播电商账号经营进入新消费；源标题、链接、发布时间不修改，不为单条新闻手动造卡。

## 排除与优先级

- 平台或主播名称只是线索，必须结合经营、产品或消费活动；“在抖音看到一则事故视频”不因此归消费。
- 普通明星恋情、婚礼、庆生、红毯穿搭、饭圈应援等私生活/八卦不自动纳入。若明确涉及品牌代言解约、收费、赔偿等商业问题，则可按实际内容归类。
- “周末推荐看什么电视剧”等没有产品/市场新闻依据的泛互动问答不纳入。
- 电影院火灾、演出场所的真实公共安全事故仍走原有社会/地域规则；战争电影上映等明确文化产品新闻不当作真实军事事件。
- 股票、ETF行情仍归金融；视频平台直接研发发布AI大模型/芯片等仍归硬科技；具体整车、电池、物流产品按原行业规则优先，不因影片联名或平台名称转成消费。
- 原文24小时过滤、来源权限限制、同事件聚类、公众号停采和微博限频不变。更改类别不会重置发布时间，不会增加来源账号或调用额外采集。

实现位置：`tools/home_categories.py`。单元测试覆盖真实漏判案例、同事件聚合、过期状态更新及跨领域反例。
